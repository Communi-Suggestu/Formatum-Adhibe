# Documentation

This folder contains implementation and usage docs for `formatum-adhibe`.

## Sections

- `architecture.md` - how Checkstyle config becomes Immaculate formatting steps.
- `configuration.md` - Gradle DSL reference for the `checkstyle(...)` workflow action.
- `hints.md` - hint YAML schema, matching rules, and conflict handling.
- `compliance-testing.md` - integration testing against `libs/checkstyle/checkstyle.xml`.

## Suggested reading order

1. `architecture.md`
2. `configuration.md`
3. `hints.md`
4. `compliance-testing.md`
